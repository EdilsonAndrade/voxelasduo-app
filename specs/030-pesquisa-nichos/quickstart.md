# Quickstart: Pesquisa de nichos

Pré-requisito: conta do Mercado Livre conectada (a mesma usada para publicar na loja).

1. Admin → **Pesquisa de nichos**.
2. Marque 1 a 4 categorias (ex: Organização para Casa). Deixe "Só 1 cor" e "Compatível com A1" marcados. Clique **Pesquisar**.
3. Cada categoria aparece ao terminar (15–40 s na primeira vez; instantâneo nas próximas 24h).
4. Em uma oportunidade, clique **Abrir no MakerWorld** → na página, "Abrir no Bambu Studio" para confirmar o tempo.
5. Clique **Levar para a calculadora** → a calculadora abre com nome, link, tempo e gramas.
6. Pesquisa por link: cole o link da Shopee (e/ou do ML) no campo "Achei um produto" → confira o nome extraído → **Buscar modelos**.

Testes automatizados: `npx vitest run lib/nichos lib/produtos app/api/admin/nichos`.
